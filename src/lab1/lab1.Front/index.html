Імпорт та Експорт Даних

Формати: CSV, JSON, XML та XLSX. Дані зберігаються в оперативній пам'яті сервера.

CSV

Comma-Separated Values

POST/GET /api/v2/Csv/*

Імпорт або експорт датасету у форматі CSV.

JSON

JavaScript Object Notation

POST/GET /api/v2/Json/*

Імпорт або експорт структури даних у форматі JSON.

XML

Extensible Markup Language

POST/GET /api/v2/Xml/*

Обробка XML-документів з вимірюваннями якості повітря.

XLSX

Microsoft Excel Sheet

POST/GET /api/v2/Xlsx/*

Робота з таблицями Excel через бібліотеку ClosedXML.

Генерація Звітів

Формування офіційних звітів у форматах Word (.docx) та Excel (.xlsx).

Генерація звіту MS Word (.docx)

POST /api/v2/Reports/docx
OpenXML

Звіт формує титульну сторінку, опис предметної області, зведені статистичні таблиці та інтегровані ScottPlot діаграми.

Генерація аналітичного звіту Excel (.xlsx)

GET /api/v2/Reports/xlsx
ClosedXML

Файл Excel містить два окремих аркуші:

  • Air Quality Records: повний реєстр міст зі стилізованими заголовками.
  • Analytics Summary: зведені показники (середнє, медіана, min, max, розподіл за категоріями та помісячні середні).
